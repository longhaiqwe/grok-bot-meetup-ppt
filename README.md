# 我如何用 Grok Bot 陪 5 岁女儿玩和学？（极简网页版 PPT）

长沙 Grok Bot Meetup · 龙海 · 15 页极简网页演示（公开脱敏版，第 2 页仅展示周末陪伴点点图，已移除家庭实拍照片）。

- 在线预览：https://longhaiqwe.github.io/grok-bot-meetup-ppt/

## 本地打开

在当前目录起一个本地静态服务，再打开 `http://127.0.0.1:4173/#1`：

```bash
python3 -m http.server 4173
```

## 演示快捷键

- `←` / `→` / `空格` / `回车` / 点击画面左右区：翻页（第 3 页互动页支持先出图和问题，再按一次揭晓大字「高质量陪伴」）
- `1`–`4` / `T`：切换 4 套配色主题（默认 `1 暖纸`，另有 `2 极简白`、`3 夜幕`、`4 报刊`）
- `O`：打开或关闭 15 页总览视图（点击任意缩略图跳转）
- `F`：全屏演示
- `P`：打开或关闭页面画笔批注
